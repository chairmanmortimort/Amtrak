# Privacy

The Amtrak tool contacts the public amtraker.com API to fetch live train data. Your requests and IP address reach that service. No account is required, no analytics or tracking is used, and no data is stored on any server we operate.

## Permissions

The tool declares its permissions in `tool/lighttool.toml`. The merged APK also inherits Android
permissions and components from the current Light SDK dependency graph.

## Analytics and accounts

None. There is no analytics integration, no advertising, no tracking, and no account. Nothing is
collected or shared by us.

## Contact

Open an issue on the project's GitHub repository.

## Content licensing and longevity

Live train data comes from amtraker.com, a third-party community API that is not
affiliated with or endorsed by Amtrak. It is a hobby service with no uptime
guarantee; if it becomes unavailable the tool cannot show live status. No Amtrak
account or credentials are used.
